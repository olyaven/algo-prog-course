1. Чем компилируемый язык (C#) отличается от интерпретируемого (Python) с точки зрения того, когда обнаруживаются ошибки?

Сишарп принимает всю программу, обрабатывает её сразу и если что-то не так, то он откажется даже запускать эту программу. Питон обрабатывает команду построчно, из-за этого ты можешь посмотреть на какой строчке появилась ошибка

2. Что делает команда dotnet run на самом деле — из каких двух шагов она состоит?

собирает проект и запускает прогамму которая получилась

3. Зачем нужны папки bin/ и obj/ и почему их не нужно хранить в Git?

в бин компилятор кладет скомпилированную программу, в обдж служебные промежуточные файлы

4. В чём разница между git commit и git push?

коммит - это история изменений, к которой можно вернуться. пуш - это отправить код на гитхаб

5. Чем отличаются конкатенация строк через + и интерполяция через $"..."? Какой способ предпочтительнее и почему?

предпочтительнее второй. он проще читается, его удобнее использовать. отличаются тем, что $ создает строку, в которую можно вставить переменную, а + просто соединяет строки и значения

6. Что произойдёт, если разделить int на int, если результат должен быть дробным? Как это исправить?

остаток отбрасывается. если нужен дробный результат, то нужно использовать double

7. Чем const отличается от обычной переменной? Приведите свой пример, когда стоит использовать const.

константу нельзя изменить после объявления, когда обычная переменная может переписаться

8. Что такое top-level statements и чем они отличаются от классического class. Program{ static void Main() }?

топ левел программирование это программирование на высоких левелах без огромных конструкций с { { { } } }, красными строками, объявлением классов и так далее. то есть компилятор берет на себя тяжелую работу, а мне позволяет писать простой код
